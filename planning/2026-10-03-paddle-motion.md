# 乒乓球拍与自动展开动效

用户要求将「韦」字标志替换为上传的红黄乒乓球拍，页面不依赖鼠标也持续运动，滚动和打开新页面时自动展开；继续自主交付并更新 GitHub。

- 标志：统一的 Logo 组件用于页眉、页脚、个人卡片、关于页和项目页；favicon 同步替换。使用用户提供图片经内置 imagegen 去白背景后生成的透明素材，保留原上传参考。
- 持续运动：山水更明显的缓慢浮动、流动雾光、漂浮光点、球拍轻摇；保持正文文字稳定。
- 页面展开：首屏标题、摘要和入口分层展开，内页标题及内容滚动进入可视区时以卷页式裁切和轻微上升展开。元素完全离开视口后再次进入可重播；普通静态页面导航与浏览器返回均支持。
- 兼容：无 JS 时内容可见；减少动态效果时取消 CSS 和运行中的 JS 动画；页面不可见时暂停动画。观察器和动画状态均限制重复创建。
- 验证：先验证球拍静态输出断言失败，再实现素材替换；运行测试、类型检查、构建与链接验证；真实浏览器检查自主动画、滚动重入、新页展开、手机和减少动态效果；独立代码检查后推送 main。
