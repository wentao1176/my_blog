千年学府，书院文脉

湖南大学办学起源于公元 976 年创办的岳麓书院，1926 年定名湖南大学，是教育部直属全国重点大学。千年的书院传统与现代大学的探索精神，在这里相遇。

对我来说，学习不只发生在课堂和书本里。把一个想法写成程序，把一份笔记整理清楚， 或者走进一个陌生的村庄，认真听一段生活的故事，都能带来新的理解。

把想法做成作品

我在 GitHub 上分享自己的项目，也在这里记录它们的用途和实现。 其中，lite-md-viewer是一款 Markdown 编辑与预览工具，让代码、公式和图表在同一个阅读窗口中呈现。

这个博客也是一件持续完善的作品。浅蓝色的山水、轻轻移动的船与云雾， 是我为文字留出的背景；文章则用来保存做事的过程和当时的思考。

走出校园，走进苗乡

2026 年夏天，我随湖南大学计算机学院“湘伴耘途”三下乡团队， 来到怀化麻阳的石垅溪村。入户走访、支教课堂和田间观察， 让我有机会把校园里的学习与具体的生活联系起来。

这段经历写在《在石垅溪的夏天》里， 相关活动与照片也整理在麻阳苗乡暖心家园网站。
