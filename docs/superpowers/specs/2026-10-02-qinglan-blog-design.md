# 青岚 · Wentao 个人博客设计

日期：2026-10-02

## 目标与已确认方向

为 GitHub 用户 wentao1176 制作精美、优雅、便于长期维护的个人博客。用户确认博客名称为「青岚 · Wentao」，采用浅蓝色、中国古风和轻量笛乐元素。完成后将源码推送至 git@github.com:wentao1176/my_blog.git。当前本地目录为空，远程仓库可访问且没有分支引用。

## 视觉设计

- 以雾蓝、米白和墨青为主色，少量朱红作为印章式点缀。中文宋体标题搭配清晰的正文排版，字体具有本地回退。
- 桌面首页采用宽幅山水首屏、纵向题字、竹影和竹笛细节。正文区使用有节奏的留白、细分隔线和克制的卡片，不堆叠装饰。
- 图片与装饰作为独立资源保存；重要文字使用 HTML，避免嵌在图中。资产来源与许可证记录在仓库中，不直接复制参考主题源码。
- 移动端改为单列，保留视觉主题，导航可展开。支持键盘访问、清晰焦点、足够的文字对比度和减少动画偏好。
- 支持浅色与深色模式并保存偏好。音乐仅由用户主动播放，默认静音，不自动播放。

## 技术架构

使用 Astro、TypeScript 和 Markdown 构建静态网站。文章在本地内容集合中维护，构建时生成页面；互动由少量客户端脚本实现。站点基础路径与域名从配置读取，以适配 GitHub Pages 项目路径和后续自定义域名。

模块职责：

1. 站点配置：品牌、作者、导航、社交链接、站点地址、音乐与集成选项。
2. 内容层：验证文章元数据，处理草稿、排序、分类、标签、归档和阅读时间。
3. 页面层：首页、文章、文章详情、分类标签、归档、项目、关于、友链、音乐空间及 404。
4. 组件层：导航、页脚、文章卡片、目录、搜索、主题切换和音乐播放器。
5. 集成层：可选评论配置、统计配置和可替换音乐数据源；不把凭据放入客户端。

## 页面与功能

- 首页：品牌首屏、精选文章、最新文章、简短作者介绍与音乐入口。
- 文章列表：关键词搜索、分类和标签筛选，显示结果数与空状态；搜索索引从已发布文章生成。
- 文章详情：标题、日期、分类、标签、阅读时间、Markdown 正文、目录、上一篇和下一篇；代码块支持复制并显示结果反馈。
- 分类与标签：可访问的分类和标签入口及对应文章列表。
- 归档：按年份组织文章，提供明确的文章链接。
- 项目：项目介绍与真实 GitHub 链接。首版展示博客本身，不虚构作者的其他项目。
- 关于：使用 Wentao 作为公开标识，避免推断真实姓名、职业或经历。提供可修改的个人介绍示例。
- 友链：从配置读取；无数据时提供友好的空状态，不放虚构朋友信息。
- 音乐空间：笛乐主题视觉，支持配置曲目、播放暂停和音量；没有合法音源时明确提示待配置，不能伪装正在播放。若使用生成的音律演示，应标注为合成演示而非真实笛子录音。
- 通用：响应式导航、主题切换、404 页面、RSS、站点地图、SEO 元数据和分享元数据。

## 内容与扩展接口

提供数篇明确标注为示例的原创 Markdown 文章，用于展示技术笔记、生活随记和音乐主题。示例不冒充用户的真实经历。文章元数据包含标题、摘要、日期、分类、标签、封面、精选状态和草稿状态。草稿不进入生产页面、搜索索引、RSS 或站点地图。

配置中为评论、统计、音乐曲目和未来内容适配器预留清晰边界。首版提供可选 Giscus 配置入口与接入文档；未配置时不加载第三方脚本。统计未配置时不采集数据。未来 CMS 或 API 可替换内容获取层，不宣称首版存在后台或数据库。

## 错误处理与性能

无搜索结果、无友链和无音源均有可理解的状态提示。音频加载与播放失败显示提示并恢复可重试状态。非法文章元数据使构建失败并给出定位信息。资源路径统一处理基础路径，避免 GitHub Pages 子路径导致失效。图片使用适当尺寸与延迟加载；装饰避免影响正文加载和交互。

## 验证与交付

运行类型检查和生产构建；对内容过滤、分类标签与基础路径等关键逻辑做必要验证。使用真实浏览器检查桌面与移动端：首页视觉、文章阅读、搜索、导航、主题切换、音乐状态，以及链接和控制台错误。

交付源码、配置说明、内容编辑说明、扩展接入说明、资源来源记录、锁文件和 GitHub Pages 构建部署工作流。源码经验证后正常提交并推送至指定仓库，不强制推送。GitHub Pages 在线发布依赖仓库的 Pages 设置及 Actions 权限；只有实际确认发布成功后才报告在线地址，上传源码与网站上线分别验证。

## 范围边界

首版不实现账户系统、后台管理、数据库或收费服务。个人资料、真实文章和音乐资源均可通过配置补充。优先交付完整可用的阅读网站和可维护结构。
